# vigrep

Semantic grep for local text files.

## Install

Install the latest GitHub release into `~/.local/bin`:

```bash
curl -fsSL https://raw.githubusercontent.com/KerrKerrKerr/vigrep/main/install.sh | bash
```

The installer currently targets Linux x86_64 release builds.

## Build from source

```bash
cargo build --release
```
